# Student Expense Tracker 💰

## About the Project
Student Expense Tracker is a simple web-based mini project developed to help students manage and track their daily expenses. It allows users to add expenses, view total spending, search transactions, and organize expenses by category.

## Features
- Add new expenses with name, amount, category, and date.
- View total expenses and number of transactions.
- Identify the highest expense.
- Search expenses by name.
- Filter expenses by category.
- Sort expenses by date, amount, or name.
- Delete individual expenses.
- View category-wise expense totals.
- Clear all expenses when required.
- Save expense data in the browser using Local Storage.

## Technologies Used
- HTML – Structure of the website
- CSS – Styling and layout
- JavaScript – Functionality and logic
- Browser Local Storage – Saving expense data

## DSA Concepts Used
- Arrays and Objects
- Searching
- Sorting
- Array Traversal
- Data Filtering
- Aggregation using array methods

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Find the `StudentExpenseTracker.html` file.
4. Double-click the file to open it in a web browser.
5. Start adding and managing your expenses.

## Project Objective
The main objective of this project is to apply Data Structures and Algorithms concepts to a practical application while helping students monitor their daily spending.

## Limitations
- Expense data is saved only in the current browser's Local Storage.
- Data is not synchronized across devices.
- The project does not connect to bank accounts.
